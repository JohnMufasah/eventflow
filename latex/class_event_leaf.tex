\doxysubsection{Detailed Description}
Base class representing a Leaf in the Composite pattern. 

\doxylink{class_event_leaf}{Event\+Leaf} objects represent components that cannot contain child Event\+Components. Concrete event objects such as \doxylink{class_student_guide}{Student\+Guide}, \doxylink{class_food_vendor}{Food\+Vendor} and \doxylink{class_information_desk}{Information\+Desk} derive from this class.
